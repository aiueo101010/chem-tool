# 化学実験 第3実験室 図表メーカー

第3実験室（比色分析・BTBの吸収スペクトルと平衡・化学的振動反応）のレポート用の表とグラフを、測定値とスペクトルファイルからExcelファイルにするツールです。

**使う：** https://aiueo101010.github.io/chem-tool/

- 入力した値から、レポート用の表（三線表）と図をその場で表示。表は「表をコピー」でWordに貼り付け、図はPNG保存・画像コピーができます。軸の範囲はデータに合わせて自動で決まり（目盛は範囲の端まで表示）、図ごとに数値やドラッグで変更できます。凡例・近似式は重ならない位置に自動で置かれ、凡例はドラッグでも動かせます。変更はExcelのグラフにも反映されます。
- 表の見た目（三線表／横罫線／格子／見出し網掛け）と図の見た目（標準／論文風／白黒）を選べます。選ぶとすべての表・図が同じ見た目にそろいます。
- 表・図のタイトルや項目名、グラフの書式は一例です。そのまま使わず、自分が分かりやすいと思う形に変えて使ってください。
- 画面のデザインは[デジタル庁デザインシステム](https://www.digital.go.jp/policies/servicedesign/designsystem)に沿っています（色・文字・ボタン・入力欄・フォーカス表示）。図表メーカーとスペクトルグラフメーカーで共通です（`src/dads.css`）。
- ログイン不要。計算とExcelの作成はすべてブラウザの中で行い、入力した値はどこにも送信されません。
- サンプル値は架空の数値です。レポートには自分の測定値を使ってください。

## 構成
- `index.html` … 公開されるページ（`python3 build.py` で `src/` から生成）
- `src/report.js` レポートの表と図のプレビュー（Excelと同じ描画、コピー・PNG）
- `src/ui.html` 画面 / `src/app.js` 入力と表示 / `src/calc.js` 計算とシート構成 / `src/xlsx.js` Excel（xlsx）書き出し
- `src/test.js` … 実データでの動作確認用（node）
